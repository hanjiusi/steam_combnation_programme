# Steam 推荐系统 · 标签画像 × 多目标协同演示

华中科技大学《大数据导论》课程项目融合演示站。把两个协同项目合成为一个**本机一键启动、完全离线**的 Web 界面：

| 来源项目 | 位置 | 角色 |
| --- | --- | --- |
| SteamTasteAtlas（STA） | `D:\trae\SteamTasteAtlas` | 标签 IDF 画像可视化、游戏名/标签知识库、Web 基座 |
| bigdata_steam（BDS） | `D:\trae\bigdata_steam\steam-rec` | NSGA-II 多目标推荐实验（RelDCG × ILD 帕累托前沿） |

> 两个源项目保持零改动；本目录独立可运行，数据已快照固化。

## 一键启动

双击 **`启动演示.cmd`**（自动探测已运行的服务、用内置 Node 启动；服务就绪后会自动打开浏览器，约 1–2 秒。**运行期间请保持命令行窗口开启**，关闭窗口即停止服务）。

- 主页（标签画像）：<http://127.0.0.1:4319/>
- 推荐演示：<http://127.0.0.1:4319/reco.html>
- 项目报告：<http://127.0.0.1:4319/report.html>

无需安装 Node.js——`tools\windows-node\node.exe` 为内置运行时；所有数据与页面均在本目录，断网可用（推荐卡片上的 Steam 商店链接仅在点击时联网打开，不影响演示）。

需要在**其他设备**（手机 / 平板 / 任意电脑，无需同一网络）上打开？见下方 [公网访问](#公网访问在其他设备上打开汇报远程)。

## 公网访问：在其他设备上打开（汇报/远程）

默认只监听本机（`127.0.0.1`）。要让其他设备打开，请使用公网模式：

1. 确保电脑能上网，双击 **`启动演示-公网.cmd`**（服务运行在独立端口 4320，与本地模式互不影响）。
2. 等待窗口中打出公网地址（形如 `https://xxxx-xxxx.trycloudflare.com`，一般 5–15 秒）。
3. 在任意设备的浏览器打开该地址：主页、推荐演示、项目报告均可正常访问。
4. 演示期间**保持窗口开启**；关闭窗口即下线，公网地址随之失效（且每次启动地址都会变化）。

说明与注意：

- 隧道由内置的 `tools\cloudflared.exe`（Cloudflare Quick Tunnel）提供，免费、无需注册账号；该二进制已按官方 SHA256 与 Cloudflare 数字签名双重校验。
- 公网模式（`ALLOW_PUBLIC=1`）会放开「仅本机 Host」校验并兼容 HTTPS 来源校验，否则隧道域名会被 403 拒绝。
- 本机页面在 http://127.0.0.1:4320/ 照常打开。
- 请仅在需要时开启：任何拿到链接的人都能打开页面（内容均为公开演示数据），演示结束请关闭窗口。
- 新域名的首次解析可能有几秒延迟；若刚打开提示「找不到网站」，稍等几秒刷新即可。

## 推荐演示页（核心）

40 个演示用户 × 6489 款游戏 × 5 种相似度模式。页面由 `web-data/` 驱动，`tools\build_reco_data.py` 从 BDS 实验结果精确复算生成：

- **5 种模式标签页**：纯隐向量 w=0 → 混合 w=0.25/0.50/0.75 → 纯标签 IDF w=1（默认 w=0.50）
- **帕累托前沿散点图**：横轴 RelDCG、纵轴可切换 ALS-ILD / TAG-ILD，膝点高亮、可点击选点查看指标
- **10 张推荐卡片**：STA 英文名 + 标签；与用户画像重合的标签高亮；留一测试命中项带 ✓ 徽标；每卡附 ALS 基线对照
- **膝点对比条**：5 模式在等准确度门槛 ρ=0.90 下的多样性增益对比
- **三个案例用户**：A=83090（多样性提升最大）、B=60852（真实命中，默认）、C=79603（典型用户）

### 实验口径（与 BDS 逐位一致）

- 相关度：训练交互置 `-inf`，min-max 归一；`RelDCG@10 = mean(rel/log2(arange(1,11)+1))`
- 多样性：`ILD@10 = 1 - 2·triu(Vn·Vnᵀ,1).sum()/(K·(K-1))`（隐向量/标签矩阵行 L2 归一）
- 帕累托第二目标 = `(1-w)·ALS-ILD + w·TAG-ILD`（构建时逐点复算校验，最大偏差 5e-06）
- 膝点 = `argmax(RelDCG × ILD)`；结论 **w=0.5（平台区 0.5–0.75）**
- 校验：膝点均值与 `sim_w_sweep.json` 逐位一致（差 0.00e+00）；ALS Top-10 指标差 ≤ 5e-05；6489/6489 游戏名 100% 覆盖

数据来源哈希记录在 `web-data/meta.json` 的 `provenance` 字段，构建脚本可重跑（需 BDS 的 venv Python）。

## 课堂演示剧本（约 5 分钟，漏斗结构：大 → 小 → 大）

> 原则：结论永远是群体的（40 用户平均 / 11.2 万用户池），个例只是"演示载体"。

### 第 1 幕 · 立「大」：规模与实验设置（约 40 秒，口播开场）

- 一句话定位：标签画像（解释层）× 多目标推荐（决策层）协同实验。
- 规模三连：**11.2 万用户 × 6489 款游戏 × 73.1 万条真实交互**；约 3.2 万款游戏知识库对 6489 候选 **100% 名称覆盖**。
- 统一实验设置：40 演示用户（带固定随机种子抽样、可复现）、候选池 top-300、种群 150 × 60 代、种子 42——唯一变量是相似度来源。
- 点题：下文所有结论都来自群体平均，案例只是把结论"落到人身上"。

### 第 2 幕 · 画像页（`/`）：解释层从哪来（约 1 分钟）

- 点击「查看本地快照」：标签 IDF 画像——图谱节点、证据面板、指标卡（游戏数 / 时长）。
- 衔接句：推荐结果的"标签解释层"，就来自前面这 3.2 万款知识库。

### 第 3 幕 · 推荐页（`/reco.html`，导航「推荐演示」）：从分布里筛出的代表（约 2 分钟）

- 默认案例 B（60852）：指出右侧标签 chips 与「✓ 真实命中」留一测试徽标——"为什么推给它"的证据链。
- 强调来源：案例不是随手挑的——A＝多样性提升最大、B＝真实命中、C＝典型用户，从 40 人样本按指标筛出。
- 点击帕累托前沿上的点（如膝点）、切换纵轴 ALS-ILD ↔ TAG-ILD，讲准确度与多样性的权衡。
- 切到案例 A（83090）：多样性 0.39 → 0.98——同一结论下不同用户收益不同（用户异质性）。

### 第 4 幕 · 收「大」：群体结论（约 1 分钟）

- 依次切换 5 个模式标签页，看膝点对比条（**40 用户平均**、等准确度门槛 ρ=0.90）：纯隐向量多样性低、纯标签牺牲准确度，**w=0.5–0.75 平台区**。
- 收尾数字：膝点相比纯 ALS 基线，多样性 +16%、准确度仅降 3%——群体平均结论，个案只是注脚。

### 常见问题排查

- 端口被占用：修改 `.env` 中 `PORT=4319` 为其他端口后重新启动（如 4321）。
- 页面打不开：确认命令行窗口未关闭；先访问 `http://127.0.0.1:4319/healthz` 应返回 `{"ok":true}`。
- 双击无反应：在**文件资源管理器**中双击（在 IDE 里点击只会打开源码文本）；或手动启动：在命令行运行 `tools\windows-node\node.exe server.mjs`，然后浏览器访问 http://127.0.0.1:4319/。
- 用户下拉为空：说明 `web-data/` 缺失，运行 `tools\build_reco_data.py` 重新生成。
- 公网地址打开报 403「仅支持本机访问」：说明隧道指向的是本地模式的服务——请确认是用 `启动演示-公网.cmd` 启动的（它使用独立端口 4320）。
- `启动演示-公网.cmd` 窗口里长时间没有公网地址：确认电脑可上网（校园网受限时可换手机热点重试）；实在无法穿透时，可改用本地模式演示。

## 目录结构

```
combination\
├─ 启动演示.cmd            # 一键启动（内置 Node、healthz 探测、开浏览器）
├─ 启动演示-公网.cmd        # 公网模式：独立端口 4320 + Cloudflare 隧道（见上）
├─ server.mjs               # 静态服务 + /api/*（画像 / 推荐 / 状态；ALLOW_PUBLIC=1 开启公网模式）
├─ .env                     # PORT=4319, PROFILE_ENGINE=node
├─ public\                  # 页面：index.html（画像）/ reco.html（推荐）/ report.html
├─ web-data\                # 推荐演示数据（meta / users / items / reco\<uid>.json ×40）
├─ data\                    # STA 画像数据（catalog / snapshots / public-steam 等）
├─ tools\
│   ├─ windows-node\        # 内置 Node 运行时（离线保证）
│   ├─ cloudflared.exe      # 公网隧道客户端（Cloudflare 官方签名，已校验 SHA256）
│   ├─ tunnel.mjs           # 启动隧道并把公网地址打印出来
│   └─ build_reco_data.py   # 从 BDS 结果复算生成 web-data（含三重校验）
└─ src\                     # STA 服务端模块
```
